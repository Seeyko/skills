## Le style
- Les captures App Store de Moonjar, pour la mise en page.
- Une aquarelle « faite main » (bords qui fusent, pigment qui se dépose, grain du papier) plutôt qu'une illustration vectorielle plate.
- Le format `DESIGN.md` de Google Labs : https://github.com/google-labs-code/design.md
