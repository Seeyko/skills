# Contribuer

Les issues et les PR sont les bienvenues.

## Une idée, une erreur

Ouvre une issue. Dis la règle ou le skill concerné, ce qui ne va pas et ce que tu proposes.

## Une PR

- Une règle dit quoi faire, quand, pourquoi, et comment vérifier qu'elle est suivie.
- Elle vient d'un vrai retour : un produit livré, un test avec des gens, une source lue. Cite la source dans [`CREDITS.md`](CREDITS.md).
- Elle vaut pour d'autres projets que le tien. La réponse d'un produit (un prix, un nombre d'écrans) va dans une étude de cas.
- Mets à jour `memory/lessons.json` dans la même PR. `python3 scripts/check-lessons.py` doit passer.
- Rien de personnel : pas de nom, d'e-mail, de compte, de domaine privé, de secret.
- Le texte est en français, court, au tutoiement. Les noms de fichiers et de skills sont en anglais.

Chaque PR est relue avant d'entrer dans `main`. Personne ne pousse directement sur `main`.
